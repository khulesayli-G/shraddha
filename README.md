# Shraddha Ghotkule — Digital Marketing Portfolio

A responsive portfolio website for a Digital Marketing Executive, built with HTML, CSS, and vanilla JavaScript and designed for GitHub Pages.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive layout, colors, and visual styling
- `script.js` — mobile navigation and current footer year
- `assets/Shraddha_Ghotkule_Resume.pdf` — resume PDF used by the resume buttons

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `digital-marketing-portfolio`.
2. Open the new repository and choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` to the repository's top level.
4. Upload the `assets` folder with the resume PDF inside it. Keep the folder and filename unchanged unless you also update the links in `index.html`.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Choose branch `main` and folder `/(root)`, then click **Save**.
9. Wait a few minutes and open the URL shown in the Pages section. It should look like `https://YOUR-GITHUB-USERNAME.github.io/digital-marketing-portfolio/`.

## Update the portfolio

Edit `index.html` to update text, experience, projects, or contact details. Edit `style.css` to change the design. Keep the filenames and relative paths intact for GitHub Pages.

## Before publishing

- Confirm the public contact details are okay to share.
- Check the resume PDF opens correctly.
- Add project screenshots only when you have permission to share them.
- Add verified campaign metrics or results only when you can substantiate them.
- Confirm the certification name and dates are accurate.

## Content note

This site reflects the experience, skills, projects, education, certification, and languages listed in the provided resume. It does not claim campaign metrics or outcomes that were not supplied.
